# bayes-ab-kit

Bayesian A/B testing and experiment analysis toolkit for conversion metrics,
revenue metrics, and sequential decision-making.

Work in progress. Planned modules:

- Beta-Binomial posteriors for conversion rates
- Credible-interval superiority and expected-loss decision rules
- Normal/Lognormal revenue models
- Seeded posterior sampling
- Sequential peeking guardrails and expected sample size simulation
- Pre-test power / sample size calculation
- Synthetic experiment generator and markdown reports
- Command-line interface

Status: early development. API will change between 0.x releases.
